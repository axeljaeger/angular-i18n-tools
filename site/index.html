Behind the demos

Tooling around Angular’s own i18n.

Angular i18n Tools helps developers work with stable message IDs and runtime JSON translation catalogs using Angular’s built-in i18n, $localize, and loadTranslations().

These demos showcase the Storybook locale addon. The project also includes a VS Code extension, catalog checks for CI, and an Angular setup generator. You can explore those tools and the demo source in the repository.

This is a demonstration interface: the settings and profile are sample content. Changing language reloads the app or story so translations are loaded before Angular renders.
